# InnovaTrip
Mini project on semantic technologies – domain: tourism.
## 🎯 Selected Domain: Smart Tourism

The domain of **Smart Tourism** was chosen because it offers significant conceptual richness and allows for a practical application of Semantic Web technologies. It is also a relevant and current topic, as modern tourism systems increasingly rely on artificial intelligence, personalization, and semantic search.

This domain enables easy modeling of real-world entities such as **tourists**, **guides**, **tourist sites**, **activities**, **hotels**, and **events**, while leveraging standard vocabularies.
